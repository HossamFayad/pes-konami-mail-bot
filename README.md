# ⚽ بوت بريد بيس موبايل وكونامي (PES & Konami ID Mail Bot) 🎮

بوت تليجرام احترافي ومخصص لمتاجر بيع حسابات **eFootball (بيس موبايل)** لتوليد إيميلات دائمة، استقبال أكواد تفعيل كونامي (6 أرقام) تلقائياً، وتجهيز كروت تسليم احترافية للمشتري.

---

## 🌟 المميزات الرئيسية:
1. **إيميلات دائمة مش مؤقتة:** الإيميل والباسورد بيتعملوا بحساب دائم على `mail.tm` يقدر المشتري أو البائع يفتحه في أي وقت لتغيير الباسورد أو استقبال الأكواد.
2. **استخراج كود كونامي تلقائياً (Instant OTP):** البوت يستمع للوارد في الخلفية، وأول ما كونامي تبعت رسالة، البوت يلقط كود الـ 6 أرقام ويبعته في إشعار منفصل عريض لنسخه بلمسة واحدة.
3. **كارت تسليم جاهز للمشتري (Buyer Handover Card):** زرار يولد رسالة جاهزة للنسخ فيها الإيميل والباسورد ورابط الدخول للبريد عشان تسلمه للزبون علطول.
4. **أرشيف الحسابات السابقة (Vault):** حفظ آخر الحسابات المنشأة مع إمكانية التبديل بينها وفحص رسائلها في أي وقت.
5. **دليل ربط الحساب (Step-by-step Guide):** شرح تفصيلي لطريقة ربط بيس موبايل بـ Konami ID من داخل اللعبة.

```powershell

```

2. شغل البوت:
```powershell

```

3. افتح تليجرام وادخل على البوت:
[@pes_store_mail_bot](https://t.me/pes_store_mail_bot) واضغط `/start`!
